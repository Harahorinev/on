# Frontend — Расписание

React (Vite + TypeScript) приложение для записи на слоты и управления расписанием компании.

## Запуск

1. Установить зависимости: `npm install`
2. Запустить бэкенд (в папке `backend`): `npm run dev` (порт 3001 по умолчанию)
3. Создать файл `.env` (по желанию):
   ```
   VITE_API_URL=http://localhost:3001
   ```
4. Запустить фронтенд: `npm run dev`  
   Приложение откроется на http://localhost:5173

## Сборка

- `npm run build` — сборка в `dist/`
- `npm run preview` — просмотр собранного приложения

## Страницы

- **/** — главная
- **/login**, **/register** — вход и регистрация (роли: пользователь / компания)
- **/companies** — список компаний (только для пользователя)
- **/companies/:id/schedule** — расписание компании и запись на слоты
- **/bookings** — мои записи (только для пользователя)
- **/company** — кабинет компании: создание компании и слотов (только для компании)
